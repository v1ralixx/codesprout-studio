# CodeSprout Studio

Бесплатная русскоязычная мастерская для начинающих программистов. Изучай HTML, CSS и JavaScript, меняй примеры и сразу проверяй результат — прямо в браузере.

## Возможности

- Три редактора кода: HTML, CSS и JavaScript.
- Предпросмотр запускается по кнопке или обновляется автоматически.
- Учебные примеры: приветственная страница, карточка профиля и счётчик.
- Консоль показывает `console.log`, предупреждения и ошибки JavaScript.
- Проект автоматически сохраняется только в локальном хранилище браузера.
- Скачивание проекта в ZIP с раздельными файлами HTML, CSS и JavaScript.
- Адаптивный интерфейс, поддержка клавиши Tab и сочетания Ctrl+Enter.
- Не нужны установка, сборка, регистрация или ключ API.

## Запуск

Скачай папку или клонируй репозиторий. Открой `index.html` в браузере — и можно начинать.

Для локального HTTP-сервера (опционально) открой PowerShell в папке проекта и выполни:

```powershell
py -m http.server 8000
```

Затем открой в браузере `http://localhost:8000`.

## Файлы проекта

- `index.html` — разметка приложения.
- `styles.css` — оформление.
- `app.js` — редактор, предпросмотр, примеры и экспорт проекта.
- `favicon.svg` — иконка.

Шрифт подгружается из Google Fonts, если доступен интернет; без него браузер использует системный шрифт.

## Заметка о безопасности

Пользовательский код выполняется в изолированном `iframe` с sandbox. Этот простой учебный инструмент не предназначен для обработки секретов или запуска неизвестного кода в доверенной среде. Избегай вставки секретных ключей и персональных данных.
